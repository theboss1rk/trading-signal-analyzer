
# Trading Signal Analyzer

A lightweight Streamlit research tool for multi-indicator trading signals.

## Run
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## CSV
Required columns:
`time, open, high, low, close`

## Important
This version is intentionally signal-only. It does not place trades or promise accuracy.
Use historical and paper-trading tests before considering real money.
